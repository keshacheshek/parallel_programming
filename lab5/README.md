## 1. Цель работы
Целью работы является получение практических навыков работы с реальными суперкомпьютерными системами. В задачи входит: изучение удаленного доступа к кластеру по протоколу SSH, настройка среды окружения Intel Parallel Studio, компиляция MPI-программ под архитектуру Intel Xeon и запуск вычислений через планировщик задач Slurm.

## 2. Теоретические сведения
Работа на суперкомпьютере отличается от локального запуска использованием **планировщика задач (Job Scheduler)**. На кластере «Сергей Королёв» используется Slurm. Пользователь не запускает программу напрямую, а формирует пакетное задание (batch job), в котором указывает необходимые ресурсы:
*   Количество вычислительных узлов (`nodes`).
*   Количество задач на один узел (`ntasks-per-node`).
*   Очередь (раздел) исполнения (`partition`).

Для компиляции использовался специализированный компилятор **Intel C++ Compiler (mpiicpc)**, который оптимизирован под процессорные инструкции Intel Xeon и обеспечивает высокую производительность в связке с библиотекой Intel MPI.

## 5. Описание реализации
Программа реализует параллельное умножение матриц методом горизонтальной декомпозиции (как в Лабораторной работе №3). 
Основные этапы:
1. Инициализация MPI и рассылка размерности матрицы.
2. Процесс 0 распределяет строки матрицы A между узлами кластера (`MPI_Scatter`).
3. Матрица B рассылается всем узлам целиком (`MPI_Bcast`).
4. Вычисления проводятся на 8 независимых процессах, распределенных по 2 вычислительным узлам.
5. Результаты собираются в единый массив на главном узле (`MPI_Gather`).
